# Ressources publiques

Les SVG validés du skill jokkodev-ui-fidelity sont copiés sans modification dans brand/ : signature, monogramme et favicon, avec variantes pour fond sombre. favicon.ico est placé dans src/app/ selon la convention Next.js. Le composant Brand conserve leur ratio et une zone libre de 10 % de la hauteur.

Les polices locales sont dans src/styles/fonts/, chargées par next/font/local. Sources et notices OFL : docs/licenses/fonts/. Aucun téléchargement de police au build ni dans le navigateur vers un tiers.

L’illustration autonome de l’accueil (Afrique, réseau et logo) n’est pas fournie dans le skill. Ne pas extraire une capture contenant du texte d’interface ni inventer un substitut pour le lot accueil.
