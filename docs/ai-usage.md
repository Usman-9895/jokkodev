# Assistance IA

Le socle initial a été rédigé avec l’assistance de Codex à la demande de l’équipe DevTeranga : organisation, configuration, code technique, tests et documentation. Les documentations officielles et métadonnées npm ont été consultées pour les versions et compatibilités. Aucun code d’un ancien projet n’a été repris ; aucun logo ni police tiers n’avait été intégré dans ce socle initial.

L’équipe doit relire architecture, sécurité, résultats de vérification et licences avant publication. Les types API proviennent d’openapi-typescript, le client Prisma de son générateur. Les résultats réellement exécutés et limites sont consignés dans docs/verification.md. L’assistance IA ne constitue ni une validation de sécurité ni un avis juridique. Aucune licence du code original n’a été décidée ou ajoutée.

Le 12 octobre 2026, Codex a également assisté la préparation de la publication dans le dépôt GitHub créé par l’équipe : inspection en lecture du distant, configuration Git locale autorisée, exclusions, règles de collaboration et recherche de secrets sans afficher leurs valeurs. Le premier commit et les push restent soumis à une validation explicite préalable de DevTeranga.

Le 13 octobre 2026, assistance au lot 1 frontend selon le skill jokkodev-ui-fidelity : tokens, composants, catalogue de développement, intégration sans modification des logos validés et des polices officielles avec notices OFL. Revue sur Chromium isolé et examen des captures ; aucune API métier utilisée. Sources, conventions et limites figurent dans docs/frontend/ et docs/licenses/fonts/. Après validation de la revue visuelle, l’équipe a explicitement autorisé le commit, le push de feature/frontend-design-system et la création d’une PR vers develop. Aucune fusion n’est autorisée.
