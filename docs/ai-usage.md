# Assistance IA

Le socle initial a été rédigé avec l’assistance de Codex à la demande de l’équipe DevTeranga : organisation, configuration, code technique, tests et documentation. Les documentations officielles et métadonnées npm ont été consultées pour les versions et compatibilités. Aucun code d’un ancien projet n’a été repris ; aucun logo ni police tiers n’avait été intégré dans ce socle initial.

L’équipe doit relire architecture, sécurité, résultats de vérification et licences avant publication. Les types API proviennent d’openapi-typescript, le client Prisma de son générateur. Les résultats réellement exécutés et limites sont consignés dans docs/verification.md. L’assistance IA ne constitue ni une validation de sécurité ni un avis juridique. Aucune licence du code original n’a été décidée ou ajoutée.
