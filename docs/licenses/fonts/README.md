# Polices locales — lot 1

Fichiers officiels récupérés le 13 octobre 2026 depuis le dépôt google/fonts, sans modification ni conversion : Inter[opsz,wght].ttf, SourceSerif4[opsz,wght].ttf et JetBrainsMono[wght].ttf. Utilisation via next/font/local ; pas de téléchargement à distance pendant le build.

sources.json contient les URL de provenance, identifiants de blobs Git, empreintes SHA-256 et chemins locaux. Les empreintes Git des fichiers téléchargés ont été comparées aux blobs déclarés par l’API officielle : identiques. Les licences SIL Open Font License 1.1 et copyrights originaux sont conservés séparément dans les trois fichiers *-OFL.txt.
